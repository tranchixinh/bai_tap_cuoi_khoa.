Crawler tin tức

Nhập URL một bài viết trên dantri.com.vn, hệ thống sẽ lấy nội dung, chuẩn hóa thành JSON và lưu vào LocalStorage.

Cách dự phòng: nếu bấm Crawl bị lỗi, dán mã nguồn HTML của bài viết vào đây

Mở bài viết trên dantri.com.vn → nhấn Ctrl+U → Ctrl+A, Ctrl+C → dán vào ô dưới → nhập đúng URL bài ở ô phía trên → bấm Crawl.
